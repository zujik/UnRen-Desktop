Pause

Function: Pause( delay)

Returns a transition that shows the new screen for delay seconds.

This is useful for implementing a puase that behaves as a transition does, one that is skipped when transitions are.

Example

# This will show the interstitial if the user has transitions enabled. 
# If the user turns off transitions, nothing will be shown.

scene bg interstitial
with dissolve
with Pause(2)

scene bg another place
with dissolve
